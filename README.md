Několik výukových aplikací pro děti kolem 11 let. Aplikace je možné spustit na mobilním telefonu nebo desktopu.

Číslovky s husou: prosvičuje anglické základní a pořadové číslovky.
Dělení násobení procvičuje dělení se zbytkem a hledání největšího společného jmenovatele.
Morseovka procvičuje prijímání písmen morseovy abecedy. (Zatím nefunguje offline, resp.přestane správně fungovat, jakmile se updatuje paměť prohlížeče.)

Postup pro instalaci a spuštění: 
1. stáhnout html soubor do zařízení.
2. vytvořit zástupne html souboru na ploše.
3. Klihnutím spustit html soubor v prohlížeči.
